Ejemplo: Color de fondo La propiedad bgcolor permite cambiar el color de fondo de una página web. Se agrega dentro de la etiqueta body y puede usar nombres de colores (como red, blue, green) o códigos hexadecimales.
Ejemplo: Color link Los colores de los enlaces pueden modificarse usando link, vlink y alink dentro de la etiqueta body.

Ejemplo: Alineación Horizontal La alineación horizontal permite ubicar el contenido dentro de una celda hacia la izquierda, centro o derecha utilizando el atributo align.
Ejemplo: Alineación Vertical La alineación vertical permite posicionar el contenido dentro de una celda arriba, al centro o abajo utilizando el atributo valign.
